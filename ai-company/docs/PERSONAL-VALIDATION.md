# 개인 운영 기능과 레슨퀘스트 실증

기준일: 2026-09-10. 실제 모델 흐름과 산출물 검증을 완료했으며, 대표의 결과 수용은 대기 중이다. **하루 약 30분으로 운영 가능한지는 아직 미측정**이다. 1~2주 동안 대표가 실제로 입력한 기록이 있어야 판단할 수 있다.

## 사용 위치와 실행

현재 실제 기록 화면: `http://127.0.0.1:4312`. 상단 프로젝트에서 **레슨퀘스트 · 식별자 회귀 검증**을 선택한다. `4314`는 실제 실적으로 집계하지 않는 UI 테스트 전용 데이터다.

- **대표 화면 → 목표·성과**: 목표·우선순위·완료 기준 저장. **자율 운영**에서 적용 범위와 한도를 확인하고 시작한다.
- **대표 화면 → 관찰 설정**: PO 창구/CTO, 긴급 조건, 1주/2주 관찰 기간, 기존 Codex 방식 비교 기록.
- **대표 화면 → 내 시간**: 시작·종료 타이머, 실제 시간 조정, 사후 입력, 날짜별 누락 여부 확인. 프로젝트 업무와 도구 관리 부담을 분리한다.
- **대표 화면 → 오늘 확인**: 묶인 결정에 답변, 변경 파일·검증 근거·대화 확인, 수용 또는 오류/요구사항 변경을 구분한 수정 요청.
- **대표 화면 → 회의·개선**: 필요한 참여자만 안건에 연결하고, 반복 질문/수습 근거에서 지침 후보를 검토·활성화한다. 경력 화면과 기존 QA 경험·피드백 기능도 유지한다.

앱을 다시 시작할 때 **UI와 실행기에 같은 원장 경로를 지정**한다. 기본 `.local/data`는 별도의 회사다. 인증 값을 파일이나 채팅에 넣지 않는다.

이 문서의 실제 원장·스크린샷·실행 원문 및 특정 개인 원장을 수정하는 일회성 실증 스크립트는 로컬 보관 자료다. 공개 저장소에는 앱 소스, 재현 가능한 제어 테스트와 검증 요약을 포함한다. 공개 소스만 새로 받았을 때 개인 실증 기록이나 그 전용 스크립트가 함께 제공되는 것은 아니다.

```powershell
Set-Location C:\Users\Raina\Desktop\RainCloud\ai-company
$env:COMPANY_DATA_DIR = Join-Path $PWD '.local/autonomy-live-verified/data'
$env:PORT = '4312'
.\start-company.ps1
```

이미 4312 웹 서버가 실행 중이면 같은 포트로 중복 실행하지 않는다. 현재 전체 중지는 켜져 있다. 실행기 기동 자체는 중지를 해제하지 않는다. 프로젝트 누적 호출 한도와 작업/턴 시간 한도도 별도로 확인해야 한다. UI를 닫아도 실행기는 동작하지만 컴퓨터 종료·절전 중에는 동작하지 않는다.

독립 검토의 1차 실패 및 수정 후 최종 점수는 [독립 검증 보고서](PERSONAL-INDEPENDENT-REVIEW.md)에 보존한다. 사전 기준은 [검증 기준](PERSONAL-ACCEPTANCE.md)이다. 검증자가 발견한 부모 산출물 누락, 취소 업무 재개, 정보 답변의 권한 확대, 회의 후속 메시지 누락/부분 큐 생성, 이전 단계 질문 재사용을 수정하고 회귀 테스트를 추가했다.

마지막 실제 원장 화면 검사에서 `.local` 안의 검증 파일 다운로드가 HTTP 409로 실패했다. Express의 숨김 경로 기본 차단을 확인하고, 인증·프로젝트·작업 폴더의 실제 경로 경계를 확인한 후에만 다운로드를 허용하도록 수정했다. 숨김 경로 성공/다른 프로젝트와 외부 파일 차단 회귀를 추가했으며 실제 근거 다운로드를 다시 확인했다. 앞선 독립 판정은 이 수정의 재검증 전까지 보류했고 최종 보고서에 과정을 남겼다.

브라우저 자동화의 두 초기 중단은 선택자 오류였다. 동일 label의 select 및 두 개선 후보를 구분하도록 테스트를 수정했고, 성공한 입력을 지우지 않은 채 나머지 검증을 이어 완료했다. 실패/최종 로그 모두 `.local/personal-ui/verification*.json`에 남아 있다.

## 남은 제약

- 실제 1~2주 관찰, 대표 개입 시간, 첫 검토 수용률, 운영 지침 효과는 아직 미측정이다. 테스트 시간을 실제 실적으로 세지 않는다.
- 이번에는 좁은 식별자 계약 suite를 검증했다. 전체 레슨퀘스트 monorepo lint/type/build와 서비스 통합·배포를 통과했다고 주장하지 않는다.
- 원격 Codex 작업 조회와 로컬 committed clone 검증까지 연결했다. 회사 앱이 원격 Mac에서 직접 실행기를 제어하거나 미커밋 작업과 자동 통합하는 기능은 아직 없다. 실제 검토 브랜치는 로컬에 있으며 push·병합·배포하지 않았다.
- 긴급 조건은 열린 대표 화면에서 즉시 표시한다. 브라우저가 닫힌 때의 외부 알림 발송은 연결되지 않았다. 묶음 확인 시각은 대표 화면의 운영 설정이다.
- 테스트 의존성은 검증용 폴더에 고정 버전으로 준비했다. 다른 프로젝트의 ignored 의존성을 자동 설치·복제하는 기능은 없다.
- 개인 로컬 앱이다. 여러 사용자의 인터넷 공개 서비스나 강한 OS 격리 기능은 이번 범위가 아니다.
