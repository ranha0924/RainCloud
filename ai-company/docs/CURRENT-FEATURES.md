# 지금 사용할 수 있는 기능

2026-09-10 기준. 웹 화면과 실행기는 로컬 PC에서 실행한다. 프로젝트를 연결하지 않아도 회사 앱과 채용 화면은 사용할 수 있다.

| --- | --- | --- |
| 프로젝트 관리 | 프로젝트 등록·전환, 직원 배정, 자료·목표·기억·대화·권한·사용량 분리 | 코드 업무에는 로컬 Git 최상위 폴더와 허용 경로·검증 명령이 필요 |
| 직원 채용·관리 | 11개 직무의 가상 지원자 33명 확인, 면접·동일 과제 비교, 직접 채용, 직원 지침 저장 | 프로필은 가상 템플릿. 면접·비교 응답에는 실제 모델 호출이 필요 |

## 현재 기록으로 시작하기

기존 실제 기록이 있는 이 컴퓨터에서는 `http://127.0.0.1:4312`에서 **레슨퀘스트 · 식별자 회귀 검증**을 선택한다. 목표는 **대표 화면 → 목표·성과**, 시간은 **내 시간**, 결과와 질문은 **오늘 확인**에서 본다.

현재 실제 원장은 전체 중지 상태이며 실행기도 꺼져 있다. 기록 조회·목표/시간 입력·결과 확인은 가능하다. 새 모델 작업을 진행하려면 [실행 안내](PERSONAL-VALIDATION.md)에 따라 같은 데이터 경로의 실행기를 켜고, 전체 중지와 프로젝트별 한도를 확인한다. 레슨퀘스트 검증 프로젝트는 기존 누적 호출 한도 6회를 모두 사용했으므로 다음 업무에는 그 한도를 조정해야 한다. 토큰 무제한 설정은 호출 수 제한을 해제하지 않는다.

새로 저장소를 받으면 직원·프로젝트·실제 실행 기록은 자동으로 내려오지 않는다. 로컬 DB와 인증은 Git에서 제외한다. [README](../README.md)의 설치·로그인·프로젝트 등록 순서로 시작한다.

## 아직 연결되지 않은 부분

- 원격 Mac의 레슨퀘스트 작업 공간을 회사 앱 실행기가 직접 제어하는 연결. 이번 검증은 출처를 확인한 커밋의 별도 로컬 복사본에서 수행했다.
- WorkAdventure 화면, 실제 Jarvis 제품 연결. 직원별 대화 API는 준비돼 있지만 외부 제품 연결은 별도다.
- 브라우저를 닫았을 때 외부 푸시·메일·메신저로 즉시 알리는 기능.
- 승인 이후 실제 외부 발송·지출·운영 배포·데이터 삭제를 수행하는 커넥터.
- Vercel에 웹 화면만 배포해서 로컬 실행기·SQLite·Git 작업까지 계속 동작시키는 구성.
- 모든 직무의 실제 업무 품질, 전체 레슨퀘스트 서비스 회귀, 1~2주 운영 효과 검증.

구현과 작은 실제 업무의 최종 독립 검증은 [회사 앱 98점 / 레슨퀘스트 수정 95점](PERSONAL-INDEPENDENT-REVIEW.md)이다. 이 점수는 위 미연결 기능이나 장기 효과를 대신하지 않는다.
